学习好电视 · 电视版安装说明
========================================

一、先确认电视是不是安卓系统
1. 电视设置里如果有「应用商店」能装第三方应用，多半是安卓电视。
2. 看「设置 → 关于本机 / 系统信息」，写着 Android 版本 7.0 / 9 / 11 等，就是安卓电视。
3. 能装：小米、红米、海信、TCL、创维、酷开、长虹、康佳、索尼（安卓款）、当贝/天猫魔盒、各种安卓机顶盒。
4. 装不了：三星（Tizen）、LG（webOS）、华为鸿蒙 NEXT 智慧屏（非安卓兼容模式）。

二、安装（两种方式，任选一种）

方式一（推荐）：电脑上的「电视安装助手」
1. 把 电视安装助手.exe 放到一台和电视连着同一个 WiFi 的 Windows 电脑上，双击运行。
2. 电视上先开开发者模式：
   设置 → 关于 → 连续点「版本号 / 系统版本」7 次 → 出现「开发者选项」
   进「开发者选项」→ 打开「USB 调试」和「网络调试 / ADB 调试 / 无线调试」。
3. 助手窗口里点「扫描局域网」，找到电视后点选它，再点「连接并安装」。
   电视上可能弹出「允许调试」的确认框，用遥控器选「允许 / 确定」。
4. 装完可以点「设为电视桌面」（想用严格模式时用），然后打开电视上的「学习好电视」。

方式二（不需要开发者选项）：电视浏览器下载
1. 双击运行 电视安装助手.exe（电脑和电视同一个 WiFi）。
2. 窗口里会显示形如 http://192.168.1.10:8899/ 的地址。
3. 在电视「浏览器」里输入这个地址，下载「学习好电视」安装包并安装；
   提示未知来源时选「允许安装」。
4. 电视上没有浏览器时，用当贝市场的「远程安装」功能打开同一个地址也可以。

三、两种使用模式
1. 普通提醒模式（默认）
   家长想看管控情况时打开电视上的「学习好电视」，首页显示今天还能看多久。
   时间用完会弹浮窗提醒（需要允许「显示在其他应用上层」）。
2. 严格模式（推荐给电视）
   在「学习好电视 → 家长管理 → 设为电视桌面」操作，然后在电视设置里把它选为默认桌面 / 主页。
   之后孩子按 HOME 键就回到学习页；时间用完时浮窗会盖在任何视频 App 上，点「去答题」就能答题解锁。
   想取消：电视 设置 → 应用 → 默认应用 → 桌面，换回原来的桌面。

四、用手机管理（手机上不用装任何 App）
1. 手机和电视连同一个 WiFi。
2. 打开电视上的「学习好电视 → 家长管理」（密码默认 123456），屏幕上会显示地址和二维码。
3. 手机扫码或输入地址（如 http://192.168.1.23:8787/），输入 6 位访问码即可：
   - 查看剩余时长、今日答题情况、错题本 TOP10
   - 一键加 15 / 30 分钟、清零今日
   - 改规则：基础时长、每组题量、通过正确率、每组奖励分钟、每天组数/奖励上限、自由时段、孩子称呼、家长密码
   - 偏科加权：可勾选一门或多门偏科（数学/语文/英语/物理/化学/生物/历史/地理/道法/编程），
     勾选后这些科目在答题中出现概率明显提高；不勾选则各科均衡随机
   - 一键更新题库（默认从 GitHub/jsDelivr 拉取，约 3 万道题）
   - 上传本地自建题库（电脑编辑器导出 JSON → 手机选文件上传）
   - 卸载电脑版：双击本文件夹「卸载学习好（家长专用）.bat」（需家长密码），
     或手机管理页最下面点「卸载」。bat 别留在孩子电脑上。

五、默认规则（都能在手机管理页改）
- 每天基础 60 分钟，不答题也能看这么多
- 答对 5 道题（正确率 80% 以上）→ 加 15 分钟
- 每天最多 8 组，累计奖励最多 120 分钟
- 自由时段 12:00-13:00、18:30-20:00（这两个时段不限制）
- 错题会被抽中更多次（做错 3 次的题出现概率约为普通题的 6 倍）

六、把自建题目放到电视上（可选）
1. 电脑上打开「题库编辑器」，录入题目并点「保存到本地题库」。
2. 点「导出给电视（JSON）」，保存成类似「本地题库-给电视-20261107.json」的文件。
3. 把这个文件发到手机（微信、QQ、数据线都行）。
4. 手机打开电视家长管理页，找到「本地题库（电脑导出 → 手机上传）」，
   点选择文件 → 选中刚才的 JSON → 点「上传本地题库」。
5. 电视上立刻生效：自建题会优先出现在答题里，官方题库（约 3 万题）继续保留；
   以后再点「更新题库」，只更新官方题库，不会覆盖你上传的自建题。
6. 想取消：同一处点「清空本地题库」，或在「学习规则」里把「启用本地题库」设为关闭。

七、常见问题
- 装不上 / 解析包错误：电视系统低于 Android 5，或安装被清理软件拦截。
- 找不到开发者选项：部分品牌叫「开发者模式」，在 设置 → 系统 → 关于 里。
- 助手提示连接失败：确认电视和电脑是同一个 WiFi（不是访客网络），并且电视上已允许调试。
- 电视没有浏览器：用方式一。
- 卸载：电视 设置 → 应用 → 学习好电视 → 卸载；或在助手窗口里点「卸载」。
- 浮窗盖不住视频：到电视 设置 → 应用 → 学习好电视 → 显示在其他应用上层，打开权限。
- 上传本地题库提示「没有可用题目」：请直接用题库编辑器里的「导出给电视（JSON）」导出的文件，
  不要手工改字段名或删掉题干/选项。
- 电脑上没找到「导出给电视（JSON）」：用本次附带的「题库编辑器（含导出给电视）.exe」，
  旧版编辑器没有这个按钮。

八、电脑版不受影响
电脑版 StudyGoodAndGood 的全部功能（锁屏答题、在线题库更新、本地题库编辑器、错题提权、名言警句）
都没有改动。这次只是给编辑器加了「导出给电视」按钮，电脑版原有功能照旧。
电视版是独立的新程序，两个设备可以各自独立使用。
