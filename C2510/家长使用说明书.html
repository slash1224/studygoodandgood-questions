1这套东西是干什么的

一句话：孩子答对题，才能继续看视频。

它不是一个“监控软件”，更像一个“零花钱罐子”。罐子里装的是看电视、玩电脑的时间。孩子想多拿一点，就得先答对几道题。

里面其实有两个程序，互相独立

电脑版（StudyGoodAndGood）：管 Windows 电脑。孩子用电脑时先看到答题页，答完才能进桌面。

电视版（学习好电视）：管安卓电视 / 电视盒子。时间用完会弹出提醒，答完题再多看一会儿。

两个可以只装一个，也可以都装。规则各管各的，互不影响。

2动手前先准备三样

  1. 一台 Windows 电脑 台式机、笔记本都行。用来装电脑版，也用来给电视装。
  2. 一台安卓电视（或电视盒子） 小米、海信、TCL、创维、长虹、康佳、当贝、天猫魔盒这一类都可以。
    三星、LG、华为鸿蒙 NEXT 这几种不是安卓，装不了。
  3. 家里的 WiFi 名字和密码 电脑、电视、手机要连同一个 WiFi。用手机热点也行。
小提醒：别用“访客网络”。访客网络会把三台设备互相隔开，手机就连不上电视了。

你手上应该有三个文件

文件名干什么用装在哪儿
StudyGoodAndGood.exe电脑版，管电脑Windows 电脑
电视安装助手.exe帮电视装软件先放 Windows 电脑上运行
学习好电视-TV版.apk电视版本体安卓电视

另外还有一个「题库编辑器（含导出给电视）.exe」，是给你自己出题用的，可以先不管它。

3电脑版怎么装

电脑版最省事，只要三步，全部是双击。

  1. 把 StudyGoodAndGood.exe 拷到电脑上 放桌面就行，不用建文件夹。
  2. 双击它 Windows 会问“是否允许”，点「是」。之后它自己复制到系统目录、自己设开机启动，全程不用你点下一步。
  3. 看到答题页，就成功了 屏幕上出现题目和孩子名字，说明装好了。下次开机也会自动出来。

想调整规则？不用在电脑前操作

电脑锁屏页右下角有个「家长管理」，点一下会显示二维码和网址。用手机扫一下，就能在手机上改规则、加时间、看错题。详见第 5 章。

装完发现没反应？先看看是不是被 360、电脑管家拦了。把它加入“信任 / 白名单”再双击一次。

4电视版怎么装

电视有两个装法，任选一个。方法一更快，方法二不用碰电视的设置。

方法一：用电脑上的「电视安装助手」（推荐）

原理很简单：电脑在同一个 WiFi 里“喊”一声，电视答应，就把软件递过去。

  1. 电视上打开“开发者模式” 电视 设置 → 关于（或“系统信息”）→ 连续点“版本号”7 次，屏幕会提示“你已成为开发者”。
    然后进 开发者选项，把 USB 调试 和 网络调试 / ADB 调试 / 无线调试 都打开。
  2. 电脑上双击「电视安装助手.exe」 电脑和电视必须连同一个 WiFi。
  3. 点「扫描局域网」 列表里会出现电视的名字（比如客厅的电视、MiTV…），点选它。
  4. 点「连接并安装」 这时电视上会跳出一个“允许调试吗”的框，用遥控器选「允许 / 确定」。等进度条走完就好。
  5. 电视上找到并打开「学习好电视」 在应用列表最后一页，图标是绿色的。

方法二：电视浏览器下载（不碰开发者选项）

  1. 电脑上双击「电视安装助手.exe」 这次不用点扫描，只看窗口里那一行网址。
  2. 记下窗口里的网址 长得像 http://192.168.1.10:8899/。每家的数字会不一样，照抄你屏幕上的就行。
  3. 在电视的「浏览器」里输入这个网址 点下载 → 安装。电视提示“未知来源”时，选「允许安装」。
  4. 没有浏览器怎么办 打开当贝市场，里面有「远程安装」，输入同一个网址也能装。

5用手机管孩子

手机上什么 App 都不用装，用浏览器打开一个网址就行。

  1. 手机连上家里的同一个 WiFi 用流量不行，因为要访问的是家里的电视和电脑。
  2. 在电视上打开「家长管理」 电视首页 → 家长管理 → 输入密码（默认 123456）。屏幕上会出现一个二维码和一个网址。
  3. 手机扫这个二维码 扫不出来就用手机浏览器手动输入那个网址，例如 http://192.168.1.23:8787/。
  4. 输入 6 位访问码 访问码就显示在电视屏幕上，照抄即可，每次打开都要输，这样孩子猜不到。

手机页面上能做的事

想做的事在哪儿点

想用自己出的题？

电脑上打开「题库编辑器」→ 录题 → 点「导出给电视（JSON）」→ 把文件发到手机（微信、QQ 都行）→ 回到手机管理页点「上传本地题库」选这个文件。

上传后电视上立刻生效。自出的题会优先出现，官方那 3 万道照旧保留；以后再点「更新题库」也不会把你上传的题覆盖掉。

电脑版也一样：电脑锁屏页点「家长管理」→ 显示二维码 → 手机扫码 → 就能改电脑那边的规则。不用跑到电脑前。

6孩子那边怎么用

孩子只会看到两件事：还剩多少时间，和一道题。

电视上

打开「学习好电视」，首页就是一个大数字：今天还能看多久。孩子点“开始学习”就能看视频（或者在电视上打开别的视频 App）。

时间快用完时，屏幕会弹出提醒。用完后画面会被一块提示挡住，上面有「去答题」按钮。

答题怎么换时间

题目从哪儿来？

内置约 3 万道初中选择题，按年级抽（7 年级 / 8 年级 / 9 年级），数学、语文、英语、物理、化学、生物、历史、地理、道法、编程都有。

孩子做错的题会更容易再次出现——错 3 次的题，出现概率大约是普通题的 6 倍。所以刷题不是白刷，错的会被反复考。

电脑上

开机就进入答题页，答完这一组才能进桌面。中途想退出？家长管理页可远程加时间，孩子自己关不掉。

两种电视模式，选一个

模式什么效果适合谁
普通提醒时间用完弹浮窗提醒，孩子点「去答题」才继续孩子比较自觉
严格模式把「学习好电视」设为电视桌面，一按 HOME 就回学习页，浮窗盖住所有视频需要盯紧一点的孩子

严格模式在「家长管理 → 设为电视桌面」里开启。想取消：电视 设置 → 应用 → 默认应用 → 桌面，换回原来的桌面即可。

7偏科加权（新功能）

孩子哪门弱，就多考哪门。勾上之后，这门课的题会明显变多。

以前题目是所有科目平均抽的。现在你可以在手机管理页里，勾选一门或多门“偏科”。勾中的科目，每一轮的出题量会翻倍加重；没勾的科目照常。

  1. 手机打开家长管理页 第 5 章那几步，扫码进来。
  2. 往下找到「偏科加权」 十个方框：数学、语文、英语、物理、化学、生物、历史、地理、道法、编程。
  3. 勾上弱的那几门，点保存 勾了就多考，不勾就保持平均。随时可以改，改完立刻生效。
建议：一次只勾一到两门，效果最明显。全勾了等于没勾——又变回平均了。

8电脑上的 AI 老师（新功能，可选）

孩子答错题时，电脑里会多出一个“AI 老师”，当场把这道题讲明白。

这个 AI 老师是装在你自己电脑里的，不联网也能用，题目和聊天内容都不会传到网上。打开方式有两种：锁屏界面点「有问题？问 AI 老师」；答题没过关时，结果页会出现「AI 老师讲解错题」。

使用限制（先看这一条）

  • 只支持 Windows 10 / 11 电脑。安卓手机、安卓电视、苹果设备暂时都不支持。
  • 电脑必须是 NVIDIA 显卡，推荐 RTX 3060 12GB 或更高。显存低于 8GB 跑不起来；8GB 只能跑小模型，会比较慢。
  • 第一次启动要加载模型，等 1–3 分钟；运行时占用约 7–8GB 显存，关掉 AI 页面会自动释放。
  1. 把 Omni-Edu 文件夹放到 H 盘 项目里有一个 Omni-Edu 文件夹，整个剪切到 H:\Omni-Edu（程序默认去这里找）。电脑没有 H 盘时，放到任意位置也可以，但需要技术人员改 rules.json 里的路径。
  2. 双击「获取运行时.ps1」，等它下载完 会从 llama.cpp 官方发布页下载约 650MB 的推理运行时（只需做一次）。下载完窗口会提示“运行时已就绪”。
  3. 先双击 OmniEdu.exe，等模型下载完 第一次打开会自动从魔搭下载模型（约 12.4GB，需要联网，等它下完，只用做一次）。之后在锁屏里问 AI 老师就可以完全离线。
提示：AI 老师只负责讲题，不改变答题规则。不想用可以不管它，锁屏答题、电视版、手机管理都照常工作。

电脑版和电视版各自保存自己的规则。在电脑的管理页改，只影响电脑；在电视的管理页改，只影响电视。

10常见问题

电视装不上，提示“解析包错误”

多半是电视系统太老（低于 Android 5），或者被电视自带的安全软件拦住了。先关掉拦截再试；还是不行就是系统不支持。

在电视设置里找不到“开发者选项”

有的品牌叫“开发者模式”，位置在 设置 → 系统 → 关于。找不到就直接用第 4 章的方法二（浏览器下载），不用开这个。

安装助手提示“连接失败”
  • 确认电脑和电视连的是同一个 WiFi，不是访客网络。
  • 确认电视上已经点了「允许调试」。
  • 把电视和电脑都重启一次，再扫描。
手机打不开管理页

三个原因：手机用的流量（要换成同一个 WiFi）；网址数字抄错（照着电视屏幕抄）；电视上的「学习好电视」被关掉了（先打开它，管理页才会在）。

访问码输错了很多次

回电视上看一眼，6 位数字就在二维码下面。也可以进「家长管理」重新看。

时间用完了，浮窗却盖不住视频

电视 设置 → 应用 → 学习好电视 → 显示在其他应用上层，把这个权限打开。

孩子把电视时间改了 / 把时钟调了

程序会记录“时间被改过”的次数，手机上能看到。改时间并不能白拿时长。

上传本地题库提示“没有可用题目”

请直接用题库编辑器里的「导出给电视（JSON）」导出的文件，不要手工改里面的字段名，也不要删掉题干或选项。

孩子答题一直不过，怎么办

在管理页把「过关正确率」调低一点（比如 60%），或者把「每组题量」调少。也可以看「错题本 TOP10」，找出他真正卡在哪儿。

两个设备都要装吗

不用。只关心电视就只装电视版；只关心电脑就只装电脑版。装了两个也是各管各的，规则分开设。

11怎么卸载

电脑版

方法一双击本文件夹里的 「卸载学习好（家长专用）.bat」，输入家长密码确认即可，几秒后清理完成。

方法二：打开手机管理页，最下面有「卸载」按钮，点一下电脑就恢复自由，几秒后自动退出。

卸载要家长密码，孩子卸不掉；这个 bat 也别留在孩子的电脑上。

电视版

电视 设置 → 应用 → 学习好电视 → 卸载。或者在电脑的安装助手窗口里点「卸载」。

如果开过严格模式，先在 设置 → 应用 → 默认应用 → 桌面，换回原来的桌面，再卸载。

卸载前顺手做一件事

把孩子的错题本截图存一下。里面能看出他哪几章一直没掌握，比成绩单还直观。
