====================================================
  Omni-Edu 本地教育大模型 · 便携版使用说明
====================================================

【重要】本文件夹已合并进「学习好」项目
----------------------------------------------------
- 电脑版锁屏里的「AI 老师」调用的就是这里的 OmniEdu.exe。
- 使用限制：仅支持 Windows 10 / 11；需要 NVIDIA 显卡，
  推荐 RTX 3060 12GB 及以上（显存低于 8GB 跑不起来，
  8GB 只能跑 4B 小模型）。
- 安卓手机、安卓电视、苹果设备暂时都不支持。
- 仓库里没有 models 和 runtime：
  · runtime 请先运行「获取运行时.ps1」下载（约 650MB，
    来自 llama.cpp 官方 b12211 Windows CUDA 12.4 发布包）；
  · 模型在第一次启动时自动从魔搭下载（约 12.4GB，需联网）。

一、这是什么
----------------------------------------------------
Omni-Edu 是北大团队开源的 K-12 教育大模型（多模态，
支持拍照讲题）。使用前先运行「获取运行时.ps1」下载
llama.cpp 便携运行时，再双击 OmniEdu.exe 即可，
无需安装 Python / CUDA。

二、目录结构
----------------------------------------------------
Omni-Edu\
├── OmniEdu.exe             ← 双击这个（自动检测硬件，选择 4B / 9B）
├── 获取运行时.ps1          ← 首次使用先运行它，下载 runtime（约 650MB）
├── OmniEdu-4B.exe          ← 旧版单模型启动器，可删除
├── OmniEdu-9B.exe          ← 旧版单模型启动器，可删除
├── 启动9B-本机4090.bat     ← 备用启动方式
├── 启动4B-家用3060.bat     ← 备用启动方式
├── models\                 ← 模型文件（约12.4GB，Q6_K量化版）
│                              （缺失时启动器会自动下载，见下）
├── runtime\llama.cpp\      ← 推理引擎（便携版，免安装）
├── assets\welcome.png      ← 启动欢迎画面背景图
├── appdata\                ← 内置浏览器数据（自动生成，可删）
└── logs\                   ← 运行日志（自动生成，排查用）

三、硬件自动检测（重点）
----------------------------------------------------
双击 OmniEdu.exe 时会自动检测 NVIDIA 显卡和显存：

  显存 < 8GB 或没有 NVIDIA 显卡
      → 运行失败，弹窗显示检测结果、失败原因和解决办法
  8GB ≤ 显存 < 16GB
      → 自动运行 4B 模型
  显存 ≥ 16GB
      → 自动运行 9B 模型

说明：
- 程序使用 NVIDIA CUDA 推理引擎，AMD / Intel 显卡和
  纯核显无法运行。
- 8GB 显存的机器会自动把上下文缩小到 8192，避免爆显存；
  10-12GB 用 16384，12GB 以上用 32768。
- 16GB 显存运行 9B 时上下文为 16384，20GB 以上为 32768。

四、使用方法（给孩子用）
----------------------------------------------------
1. 双击 OmniEdu.exe
   （程序会自动选择合适的模型；若模型文件缺失，
     会自动从魔搭社区下载，窗口下方显示进度、速度和
     剩余时间，耐心等下载完即可；中途关窗也不怕，
     下次启动会接着上次的位置续传）
2. 出现欢迎小窗口（正在加载模型），等待约 1 分钟
3. 自动弹出问答窗口（独立窗口、无地址栏，
   和普通的电脑软件一样）
4. 像微信聊天一样提问即可；左下角可上传
   题目照片，让 AI 看图讲题
5. 用完直接关闭问答窗口，后台服务会自动退出

五、迁移到另一台电脑（免环境配置）
----------------------------------------------------
1. 把整个 Omni-Edu 文件夹完整拷贝到新电脑
   （U盘/移动硬盘/局域网均可，约13GB）
2. 新电脑唯一要求：安装好 NVIDIA 显卡驱动
   （打游戏的电脑一般都已有）
3. 双击 OmniEdu.exe 即可，程序会按新电脑的显存
   自动选择 4B 或 9B，不需要手动挑
4. 首次双击 exe 可能提示“Windows 已保护你的电脑”，
   点「更多信息」→「仍要运行」即可，仅出现一次

六、常见问题
----------------------------------------------------
Q: 双击后报错或一直加载不出来？
A: 先检查 models 文件夹里模型文件是否齐全完整
   （大小见下）。不齐全也不用慌：双击 exe 会
   自动下载所选模型缺失的文件；仍有问题再看
   logs\server-*.log 里的错误信息。

Q: 模型文件可以只拷一部分吗？
A: 可以。程序只使用所选模型的 2 个文件，缺哪个
   首次双击时会自动从魔搭下载补齐（需要联网，
   下载完校验完整性）。

Q: 提示显存不足 / CUDA error？
A: 先确认显存不低于 8GB 且是 NVIDIA 显卡。程序会
   按显存自动缩小上下文；若仍不足，请关闭其他占用
   显存的程序，或改用显存更大的电脑。

Q: 问答窗口没有自动弹出？
A: 手动打开浏览器访问 http://127.0.0.1:8080

Q: 需要联网吗？
A: 不需要。首次部署完成后完全离线可用。

Q: 可以换更新的 llama.cpp 吗？
A: 可以。到 github.com/ggml-org/llama.cpp/releases
   下载最新 win-cuda-12.4 两个 zip 解压覆盖
   runtime\llama.cpp\ 即可。
